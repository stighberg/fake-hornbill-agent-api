# Postman assets

This folder contains Postman assets for exploring both the agent-facing fake contract and selected Hornbill API calls.

Files:

- `FakeHornBill-Hornbill-Agent-Demo.postman_collection.json`
- `Hornbill-Agent-Demo.postman_environment.json`

Use the fake contract first:

```text
00 - FakeHornBill Agent Contract
```

Use the Hornbill folders later when testing against a real Hornbill instance.

Do not store real API keys in exported Postman files.
